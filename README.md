# Dice Wars

Dice Wars is an original strategy game currently in development using Unity and C#. The project focuses on dice-based combat, resource management, and card-driven gameplay.

## About the Project

Dice Wars is built around customisable dice that act as the game's primary units. Players use dice rolls and cards to influence the battlefield, manage resources, and work toward victory by destroying their opponent's dice.

The game is being developed with an emphasis on modular systems, maintainable architecture, and room for future gameplay expansion.

## Development Status

The project is in early development. Current work includes die selection, basic rolling mechanics, and the underlying systems needed to support future gameplay features.

Features and mechanics are subject to change as development progresses.

## Source Code

This repository contains the C# source code for Dice Wars. It serves as the source-code appendix for the project's development diary, which documents implementation progress, design decisions, challenges, and lessons learned.

The source files are organised under `Assets/Scripts/`.

**Note:** This repository contains source code only, not the complete Unity project. Unity scenes, prefabs, materials, project settings, and other assets are not included.

## Technology

- **Engine:** Unity 6.3 LTS
- **Language:** C#
- **Version Control:** Git and GitHub
